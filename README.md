A deadpan log-style excuse from a robot vacuum that missed a spot: its sensors read the same spot as a chair leg, a wall, and a small dog, so it reclassified the spot as furniture and docked at 9% battery, undefeated. Written by a deterministic Python program in pure stdlib.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
